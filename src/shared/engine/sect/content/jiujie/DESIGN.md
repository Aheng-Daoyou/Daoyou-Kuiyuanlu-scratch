# 掌灯司设计稿

> 本稿记录掌灯司首版生产规格。目标不是继续增加独立规则，而是把“照灯记行”的行为触发机制压缩成现有宗门体系可以承载的：一套共通资源、一套共通技能底板、两条在同一底板上改变触发来源与兑现方式的灯法道途。TypeScript 定义与专项测试是战斗行为的最终依据。

## 1. 宗门身份

- 正式名称：掌灯司
- 稳定内容 ID：`jiujie`
- 属性主题：灯焰
- 宗门气质：正统、肃穆、冷峻的朝廷镇诡官署
- 灯法一：灯眼临身
- 灯法二：灯律加身
- 共通战斗资源：灯焰
- 共通核心状态：灯痕、案债
- 核心战斗形态：不可驱散的行为型 DOT 与延迟清算

掌灯司不是传统的爆发宗门。它以灯焰记录行为，以灯痕灼照行动，以案债等待结案清算。目标不是因为时间流逝而受伤，而是因为在身负灯痕时继续施法、攻击或进行其他主动行为而触发灯焰灼照。

核心循环：

```text
施加灯痕 → 目标主动行动 → 灯痕触发 → 获得灯焰 / 增加案债 → 消耗灯焰清算
```

两条灯法不拥有两套互不相干的资源和技能，而是共享同一循环：

- 灯眼临身：更多通过自身承伤获得灯焰，再把承受的灾厄归还。
- 灯律加身：更多通过敌人行动触发灯痕获得灯焰，再把目标的案债提前兑现。

## 2. 背景设定

烬洲之上，烛京为心，九灯为界。梦涎并非天恩，而是天上「天翁」的梦涎——掌灯司正是那个负责「不让世人知道真相」的朝廷机构。它登记、编号、镇压诡异，也记录每一个在灯下出手的人。

灯焰不是情绪化的惩罚。它只记录：

- 谁引来了灾厄；
- 谁承受了灾厄；
- 谁试图逃避灾厄；
- 谁在灯焰临身时仍然选择出手。

因此，掌灯司的灯法更接近一套严苛的律令，而非好恶分明的诛杀。

司内最高的灯楼悬于京畿雾中，九座灯位只亮其下的一重。没人知道第九盏灯后是什么，只知道历代掌灯大人继任时都必须接受「九灯问夜」。通过者可以执掌案簿；失败者会化为灯楼下的石像，继续记录后来者的脚步。

### 宗门教义

> 灯不因怒而明，罪不因弱而来。凡有所行，皆有灯听；凡有所取，皆有归处。

### 门人誓言

> 我不求无夜，只求夜有所归。

### 叙事边界

第一版不确定开山祖师的姓名、年代和最终真相。宗门背景只承担三个功能：

1. 解释掌灯司为何记录行为；
2. 解释灯痕为何不可被普通驱散；
3. 为后续九盏灯位、掌灯大人试炼和宗门剧情留下空间。

## 3. 共通战斗设计

### 3.1 宗门基础被动：《灯律裁决》

掌灯司的 `foundationPassiveId` 对应内部被动《灯律裁决》。它是所有掌灯司弟子加入宗门后即获得的共通能力，不属于任何灯法，也不占主动技能槽。

基础效果：

> **掌灯司弟子受到敌方主动法术或负面技能时，有 20% 的几率免疫整个技能。**

这里的“敌方主动法术或负面技能”指敌方施放的、带法术通道或带负面技能标签的主动技能。触发后，整个技能在施法前被拦截，伤害、治疗、控制、Buff 与技能费用效果均不执行；己方增益、自身施法和照灯指都不触发该被动。它不改变灯痕 Buff 自身的不可驱散规则。

这个被动表达的是掌灯司弟子的根本气质：灯律护持下，外来邪法、诅咒与控制未必能够落在身上。

两条灯法只能在此基础上改变后续收益：灯眼临身增加承焰与反制，灯律加身增加施罚与清算；不得替换或重复注册《灯律裁决》。

### 3.2 共通资源：灯焰

两条灯法共用唯一战斗资源：**灯焰**。

| 项目 | 设计 |
| --- | --- |
| 资源名称 | 灯焰 |
| 资源性质 | 战斗内临时资源 |
| 固定上限 | 3 |
| 主要用途 | 强化或启动共通清算技能 |
| 获取方式 | 灯痕触发、承受直接伤害、部分节点奖励 |
| 消耗方式 | 共通清算技能和部分防御技能 |
| 两条灯法差异 | 只改变获取倾向与消耗后的附加效果，不改变资源 ID |

灯焰不是怒气、法力或第二条伤害条。它表示“掌灯司弟子当前手中握有多少可以调用的灯焰”。

### 3.3 共通状态：灯痕

灯痕是掌灯司最核心的持续状态，实现为单层、不可普通驱散的负面 Buff。

基础规则：

- 灯痕由掌灯司技能施加，不可被普通驱散、净化或移除效果清除。
- 被标记目标进入一次主动行动时，灯痕触发一次。
- 目标使用主动神通时，触发造成灯焰持续伤害，并增加一层案债或推进现有案债。
- 目标使用照灯指（普攻）时，仍触发一次基础灯痕伤害，但不增加案债、不记录主罪。
- 灯痕造成的伤害不再次触发灯痕；自然结束时直接移除。

“不可驱散”是灯痕的规则身份，不是驱散失败后额外反伤。

### 3.4 共通状态：案债

案债是灯痕触发后留下的可见计数，上限固定为 3 层。共通终式可以消耗目标案债进行一次结案清算。灯痕负责“目标行动时触发”，案债负责“多次触发后的兑现”。

## 4. 共通技能底板

两条灯法共享以下基础神通：

| 技能 | 类型 | 职能 | 共通底板 |
| --- | --- | --- | --- |
| 《照灯指》 | 普通攻击 | fallback | 造成基础灯焰直接伤害 |
| 《灯听引焰》 | 主动 | 生成 | 对目标造成灯焰伤害并施加或刷新灯痕 |
| 《承灯受焰》 | 主动 | 防御 | 短暂降低受到的直接伤害；灯眼灯法额外记录承焰量 |
| 《案簿落印》 | 主动 | 标记 | 目标已有灯痕时增加1层案债并刷新灯痕 |
| 《灯牢问行》 | 主动 | 维持 | 延长灯痕或推进案债 |
| 《借焰护身》 | 主动 | 资源 | 消耗 1 点灯焰，获得短暂护盾 |
| 《灯影回响》 | 主动 | 追击 | 造成基础灯焰伤害，并根据案债追加伤害 |
| 《九灯清算》 | 主动 | 终式 | 消耗灯焰，对带灯痕或案债的目标清算 |
| 《灯律裁决》 | 被动 | 宗门基础 | 20% 几率免疫敌方主动法术或负面技能 |

## 5. 灯眼临身

以身为灯眼，主动承受来力；把承受的灾厄转成灯焰，再用共通清算归还。共享灯焰、灯痕、案债和全部共通技能。

道途专属状态：**灯眼**与**照见**。灯眼期间直接伤害记录为承焰量，第一次直接攻击灯眼的敌人被照见。

六层节点主题：开门迎焰、承焰留名、灯焰护心 → 血甲同书、问焰寻隙、借焰续眼 → 不退灯门、灯焰反照、静候灯来 → 众焰归一、灯牢追身、灯甲回生 → 真焰入簿、焰尽身还、清算留门 → 九门归焰、身为灯门、焰后再开。

## 6. 灯律加身

观察目标如何行动，在重复主罪、改变罪名与退回照灯指之间立案、追责并终审。共享灯焰、灯痕、案债和全部共通技能。

道途专属记录：**主罪**与**重犯**。主罪记录目标最近一次被掌灯司有效观察到的主动技能类别（伤罪、援罪、禁罪）。

六层节点主题：灯听记名、问行取证、初罪立案 → 伤罪加刑、援罪断供、禁罪反照 → 易罪不赦、定罪成册、庶行有录 → 重法催审、疾书追罪、三问成案 → 再犯从重、清册留案、两避成罪 → 三债终审、九罪同科、灯律不绝。

## 9. 视觉和文案基准

### 视觉

- 主色：深夜蓝、青白灯焰、暗紫、炭黑、克制旧金。
- 建筑：悬空灯楼、灯链、半毁灯门、黑金官墙。

### 文案

技能描述按以下顺序书写：

1. 先说明掌灯司弟子做了什么；
2. 再说明目标身上的灯痕或案债如何变化；
3. 最后说明消耗、清算或灯法节点带来的差异。

避免把灯痕写成普通毒、灼烧或流血；避免把灯眼写成永久嘲讽或无条件反伤。
