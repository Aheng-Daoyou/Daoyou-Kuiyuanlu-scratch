# 窥渊录 · 功法技能库（八窍基础功法/神通）

> 对应任务 #37：从零构建窥渊录功法技能库。
> 数据源：`config.ts`（`BASIC_TECHNIQUES` / `BASIC_SKILLS`）+ `starterProducts.ts`（recipe 关联）。
> 本文件记录八窍基础功法与神通的换骨命名体系。英文引擎键 / schema 判别值 / 数值零改动，只换中文显示文本。

---

## 一、定位

角色创建时，依据先天八窍，玩家获得 **1 门基础功法（被动）+ 2 门基础神通（攻/护各一）**。

- **功法**：`CultivationTechnique`，被动属性加成，是「正法」入门的种子。
- **神通**：`Skill`，主动效果，含攻击与治疗/护体两类。

功法本质 = 框架第八节「功法三轨」中的**正法**（《守灯七章》残卷，稳定、慢、主动抑制污染）。所以这些入门功法都在「教人怎么中毒最慢」——这是命名与文案的核心精神。

## 二、八窍与种子技能映射（换骨后）

| 窍 | 特性 | 功法（被动） | 攻击神通 | 治疗/护体神通 |
|---|---|---|---|---|
| 烛 | 光焰·秩序 | 照烛功 | 烛锋刺 | 灯皮护 |
| 尸 | 死亡·不腐 | 枯荣功 | 枯藤缚 | 续命灯 |
| 星 | 命运·星辰 | 坠星诀 | 坠星锥 | 星幕 |
| 渊 | 深渊·水下 | 渊火功 | 渊火指 | 渊息灯 |
| 梦 | 梦境·穿行 | 沉梦经 | 梦石坠 | 梦土甲 |
| 噬 | 吞噬·同化 | 噬风功 | 吞风刃 | 噬风息 |
| 帘 | 空间·帷幕 | 揭帘诀 | 裂幕击 | 幕隙守 |
| 疫 | 蔓延·感染 | 瘟霜诀 | 瘟霜刺 | 瘟幕守 |

> 命名原则：保留**效果属性辨识**（攻/治/护），同时融入克苏鲁意象（灯 / 梦 / 渊 / 幕 / 瘟 / 噬 / 星 / 枯 / 烛）。

## 三、换骨边界

- **英文引擎键保留**：`BASIC_TECHNIQUES` / `BASIC_SKILLS` 的键（八窍）、`AttributeType`、数值、`affixIds`、`AbilityConfig.slug`（`basic-${element}-${name}` 随中文名运行时生成，安全）。
- **recipe 关联键同步**：`starterProducts.ts` 中 `starterTechniqueRecipes` / `starterSkillRecipes` 的 key（`'烛:照烛功'` 等）需与 `config.ts` 的中文名一一对应，否则 fallback 不生效。

## 四、文案风格（克苏鲁修仙）

功法与神通描述一律走「纳秽 / 梦涎 / 守灯」语感，示例：

- 功法：`${窍}窍纳秽入门之法，导梦涎缓缓入体而不立毙，是守灯一脉最稳妥的「慢性中毒」。`
- 攻击：`${窍}窍之力凝成一点凶光刺出，乃初入灯途的攻伐手段。`
- 治疗：`${窍}窍之息回护周身，可作自保续灯之用。`
