# 第一部分 · 世界观（世界如何运转）

## 一、世界之名：烬洲

世界名为「烬洲」。烬者，燃尽之灰也；洲者，大陆也。这是一片在「灯」与「渊」之间勉力维持的陆地。

### 1.1 核心矛盾：灯与渊

烬洲的运转围绕一对根本对立展开：

- **灯** —— 文明的秩序、安全、光。灯照得到的地方，人才能安睡、交易、修行。整个世界以「灯」为界，划分安全与危险。
- **渊** —— 灯照不到之处。旧纪元的残响、不可名状的注视者、被梦涎腌坏的怪物，都藏在渊里。

灯一旦熄灭，渊就会蔓延进来。因此「守灯」不是一句口号，而是一场日复一日、以命相抵的日常。

### 1.2 天与灯：天翁

烬洲之上悬着一位「天翁」。传说整片大陆不过是天翁的一场**梦**——梦涎自天穹垂落，化作众生修炼所需的「灯油」与「灵气」。

- **天翁井**：荒原中央的巨井，井绳永远是湿的，而今天并没有下雨；井底通向天翁的传闻无人证实。
- **泡影之夜**：旧纪元终结的那个夜晚，被后世称为「泡影之夜」。幸存的旧物化作「遗种」，散落人间。

### 1.3 旧纪元与「九禁地」

在烬洲的当世之前，存在过一个更古老的纪元。旧纪元的遗迹散落在世界各处，其中凶险绝地被称为「**九禁地**」——天裂口、万灯楼、无昼渊、天翁井、长夜古道、倒悬观星台、乳母腹地等，皆是灯照不到、规则崩坏的禁区。

## 二、力量体系：守灯修行

### 2.1 九重境界（修为）

从低到高九境，对应修为深浅与寿元的跃迁：

| 阶 | 境界 | 神智上限 | 备注 |
| -- | ---- | ---- | ---- |
| 0 | **闻腥** | 100 | 初入门，未遭污染 |
| 1 | **守灯** | 95 | 筑基，正式守灯 |
| 2 | **窥渊** | 90 | 初窥深渊之秘 |
| 3 | **蚀体** | 85 | 肉身被渊气侵蚀改造 |
| 4 | **忘川** | 80 | 行走于生死之间 |
| 5 | **执灯** | 75 | 亲手执掌灯焰 |
| 6 | **掌灯** | 70 | 掌一方灯火 |
| 7 | **近神** | 65 | 逼近「非人」之境 |
| 8 | **渡渊** | 60 | 试图横渡深渊的尽头 |

每一境又分 **初期 / 中期 / 后期 / 圆满** 四小阶。

### 2.2 核心张力：神智轴

烬洲修行的铁律是——**力量越强，理智越弱**。

- 修为每上一个台阶，神智（理智）的永久上限就低一分。
- 越接近「渡渊」，人就越接近「非人」；最强的修士，往往也是离疯癫最近的人。
- 观星台的学者「知道得最多，疯得也最彻底」，是这一规则的极致写照。

### 2.3 八窍（灵根）

原「灵根」在此世界被称为「窍」或「八窍」，是修行者与天地梦涎共鸣的天赋通道。八窍对应八种属性：

**烛 · 尸 · 星 · 渊 · 梦 · 噬 · 帘 · 疫**

窍分品阶：**天窍 / 真窍 / 伪窍 / 变异窍**。

# 第二部分 · 背景故事（从何处来）

> 背景故事散见于各宗门 definition / presentation / prompt，本节将其提炼为一条完整的、可通读的烬洲叙事主线，供玩家开篇与叙事设计引用。

## 三、烬洲的来路

### 3.1 天翁与梦涎（世界如何开始）

烬洲并非「造物」之物，而更像是被**梦出来**的。

- 传说万古之前，天幕之上悬起一位「天翁」，以无穷的身量沉入长眠。
- 它每一次翻身、每一次吐息，都从空中渗下稠白的「**梦涎**」——那既是维持烬洲运转的灯油，也是让万物畸变的毒露。
- 众生以梦涎修行、以梦涎燃灯、以梦涎维生，却从不深究：**若连我们居住的大地都是别人的梦，那醒来时，我们是否一并熄灭？**

### 3.2 泡影之夜（旧纪元如何终结）

久远的过去，存在过一个比当世更昌盛的纪元——那是灯还不太需要守的时代，九座禁地尚未绝地，万灯楼仍彻夜明亮，天裂口也还只是一道风景。

**泡影之夜**终结了它。没有人说得清那一夜究竟发生了什么：

- 那夜之后，天幕被撕开一道「**天裂口**」，风从里面吹出旧纪元腐朽的味道。
- 无数灯影在同一瞬间熄灭，旧纪元的城池、王朝与飞升者，都像被吹灭的灯一样，**不曾留下名字**。
- 只有少数「侥幸」留存下来的旧物——器皿、法阵、残念、飞升者的遗蜕——从泡影中走出，化作散落人间的「**遗种**」。

### 3.3 当世：烬洲（如今如何延续）

泡影之夜后，烬洲进入了灯必须被「守」的时代：

- **灯**成为文明与野蛮的分界。灯下是秩序、交易、安眠；灯外是渊，是暗，是腌物与注视。
- 有人尝试**执灯照渊**、有人尝试**横渡深渊**、有人只是**想守着一盏灯，让一城人安睡到天明**。
- 为了在渊的阴影下活下去，烬洲兴起了以「守灯」为名的修行体系——越修越强，越强越接近失去理智的「渡渊」。

### 3.4 六家与《守灯》残卷（大势如何成形）

守灯修行有一部根本正法，据传为七章（残），被称作《**守灯七章**》。如今流布于世的，是其中被六家守灯传承各自执掌的残卷——掌灯司掌《守灯律》、太乙清都观掌《守灯录》、百戏班掌《百戏谱》、幽都地藏殿掌《幽都魂典》、白莲乳母教掌《乳母哺真解》（第五章残）、观星台掌《观星太初经》。

六家散落烬洲四方，或朝廷、或道门、或戏班、或亡者之城、或邪教、或隐世学者，各自守着一座「灯」，也各自在灯与渊的夹缝里，问一个没有答案的问题。

# 第三部分 · 数据设定（世界由什么构成）

## 四、种族与诡异

烬洲战斗敌人皆属**诡异三族**——这是本作唯一的敌人分类。原版七种族（人族/妖族/鬼魂/魔族/古兽/灵族/诡异）已彻底移除。

### 4.1 诡异三族（讳名）

诡异以「讳名」指代，残缺、错位、不可完整读出。按来源分为三族：

| 子族 | 名称后缀 | 来源 | 定位 | 气质 / 叙事 | 属性倾向 | 元素池 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| **腌物** | 执念者 | 被梦涎腌坏的凡人与尸体，保留生前执念 | 最常见野怪，执念即弱点 | 执念、腌化、成群；日常错位的恐怖 | 体魄壮实、弱神速 | 尸、噬、疫、梦 |
| **遗种** | 守则者 | 泡影之夜幸存的旧纪元残留物 | 自带规则特性，中型 BOSS | 规则、旧纪元、不可名状 | 强攻 / 法双修 | 渊、星、帘、疫 |
| **投影** | 倒影 | 天翁梦中渗出的「影子」，外边之物在天内的倒影 | 不可杀，只能封印/驱逐/交易 | 倒影、注视、非实体 | 神魂与意志极高、脆身 | 梦、渊、帘、星 |

三族战斗风格倾向：
- **腌物**：`offense → control → sustain → guard`，炼体侧重肤/筋骨（皮糙肉厚）。
- **遗种**：`control → offense → sustain → guard`，控场优先，炼体侧重脏腑/元神。
- **投影**：`control 优先`，元神倾向全场最高、筋骨最低；装配偏好 accessory > weapon > armor，典型装备「投影佩饰 / 影坠」。

### 4.2 诡异档案四档（掌灯司分级）

掌灯司以「丁丙乙甲」四档为诡异定级，对应修为区间：

| 档 | 级别 | 境界区间 |
| -- | ---- | ---- |
| 丁 | 野腌 | 闻腥 ~ 守灯 |
| 丙 | 成形腌物 | 窥渊 ~ 蚀体 |
| 乙 | 遗种 | 忘川 ~ 执灯 |
| 甲 | 注视投影 | 近神 ~ 渡渊 |

## 五、六大宗门（守灯传承）

世间有六家执掌《守灯》传承的势力，各自执一卷残章，散落烬洲各地。

### 5.1 掌灯司（jiujie）—— 朝廷 · 灯焰

- **宗门定位**：朝廷机构，登记、编号、镇压诡异。
- **执掌**：《守灯律》（总录照灯、记行、结案三法度）。
- **战斗资源**：灯焰（上限 **3**）。
- **核心机制**：以不可驱散的「灯痕」标记诡异，待结案之日一并清算；「案债」叠层。受负面技能部分免疫（灯律裁决）。
- **箴言**：`灯焰不散，夜有所归。`
- **母域**：京畿·烛京（皇城与掌灯司总部所在，灯下安全，坊市昼夜不息）。

### 5.2 太乙清都观（lingxiao）—— 正道之首 · 香火

- **宗门定位**：天下正道之首，执《守灯》第二章。
- **执掌**：《守灯录》（只论「灯从何起、当向何处照」，不订灯式）。
- **战斗资源**：香火（上限 **6**）。
- **核心机制**：燃心灯、炼香火，纯输出剑修（暴击率 + 物理穿透）；护盾吸收伤害回香火、连击回香火；在「照影游尘」与「守拙藏锋」二道（快剑/重剑）中自定守灯之途。
- **箴言**：`点灯人间，香火照生。`
- **母域**：泽州·天枢峰（半山山门，俯瞰泽国水乡）。

### 5.3 观星台（tianyan）—— 隐世学者 · 星衍

- **宗门定位**：隐世学者，执《守灯》第六章，以星象推演前后命数。
- **执掌**：《观星太初经》。
- **战斗资源**：星衍（上限 **3**）。
- **核心机制**：五行法印编排 + 生克反应（燎原/熔岩/锻锋/寒泉/滋荣等十种反应）+ 河图/洛书双道途。胜负不在单法强弱，而在每一次观星之后如何落下下一子。
- **箴言**：`观星不命，星影为缺。`
- **母域**：北荒·倒悬观星台（雪原深处倒悬崖壁，知道的真相越多，疯得越彻底）。

### 5.4 幽都·地藏殿（youdu）—— 亡者之城 · 魂火

- **宗门定位**：亡者之城中的守序势力，执《守灯》第四章，忘川水独家产地。
- **执掌**：《幽都魂典》（三魂往复、七魄离合之理）。
- **战斗资源**：魂火（上限 **3**）。
- **核心机制**：通晓三魂七魄，以术伤侵形、魂伤越防；蚀魂叠层、禁疗耐控；「招魂渡夜」与「镇魄司命」两条道途；交易物是「记忆」。
- **箴言**：`引魂归名，忘川照影。`
- **母域**：幽都（地下亡者之城，忘川水穿城而过，亡者排队入城，生人需执魂契）。

### 5.5 白莲乳母教（wuxiang）—— 邪教 · 莲念

- **宗门定位**：邪教，信奉「乳母」，执《守灯》第五章（残）。收容乱世孤女。
- **执掌**：《乳母哺真解》。
- **战斗资源**：莲念（上限 **6**）。
- **核心机制**：以皮囊为道场、以气血燃莲灯，在「胎相 / 血相 / 莲相」三相中自证哺身；「莲镜照业」（承受反照）与「哺心渡厄」（濒死横渡）两流派。
- **箴言**：`以身哺渡，视苦为灯。`
- **母域**：南疆·乳母腹地（雾瘴深处的乳母庙旧地，疫气经年不散）。
- **注**：它作恶，但它收容的人确实无处可去——道德灰域的代表。

### 5.6 百戏班（baixiban）—— 江湖艺人 · 戏念

- **宗门定位**：江湖艺人巡游天下，执《守灯》第三章，是封灵器铸造世家与情报网，也是散修之家。
- **执掌**：《百戏谱》。
- **战斗资源**：戏念（上限 **6**）。
- **核心机制**：凭一身戏念行走江湖，在「照影游尘」与「守拙藏锋」二道中自定戏途；差异化坦克剑修（护盾 + 减伤 + 反射）；「快戏/重戏」两流派。
- **箴言**：`戏演两遍，谢幕方知。`
- **母域**：雍州·班底庄（戏台连绵、商旅辐辏）。

## 六、先天命数（命签 / 命格）

先天命数是角色出生时被「注视者」标记的印记，4~5 字命名，分八品品质。

### 6.1 八品品质

**凡品 < 灵品 < 玄品 < 真品 < 地品 < 天品 < 仙品 < 神品**

品质决定命数效果的数值强度（凡品 1.0x ~ 神品 4.5x），高品命数（地品及以上）可能附带「双面性」——吉中带凶，凶中带吉。

### 6.2 命数分类（效果维度）

命数按效果分为正向（吉）与负向（凶）两大类，覆盖以下维度：

**正向命数（举例）**：
- 闭关效率（灯下坐 / 守灯骨 / 灯髓之躯…）
- 参悟加速（夜半耳明 / 窥雾眼 / 窥渊真瞳…）
- 突破加成（临灯有回旋 / 渡口灯明 / 灯主命格…）
- 自然恢复（灯下回息 / 长明之躯 / 续灯轮回体…）

### 7.3 关键地标

- **烛京**：天下最大的「灯」，皇城与掌灯司总部所在。
- **天裂口**：天幕上撕开的旧裂口，灯照不进，风从里面吹出旧纪元的味道。
- **灯塔港**：灯外海边缘最后一座港城，灯塔彻夜不熄，严禁私斗，出港便是渊的领地。
- **鬼市**：幽都外围市集，秤翁以「信」称量记忆与诡珍，深处不许点灯。
- **万灯楼**：每逢海上大雾便浮出灯影的旧纪元高楼，万灯长明，却照不见来路。
- **无昼渊**：终年不见天光的巨渊，灯照不到渊底，渊里有人应答你的名字。
- **忘川渡**：地下亡者之城的门户渡口，亡者排队入城，生人需执魂契。
- **天翁井**：荒原中央巨井，井绳永远是湿的。
- **长夜古道**：通往旧纪元尽头的古道，走完全程者可窥渡渊真相。

## 九、材料与制香（造物）

### 9.1 材料类型

**seed（种子）· herb（药草）· ore（矿石）· monster（妖兽）· tcdb · aux · gongfa_manual（功法手抄）· skill_manual（神通手抄）**

### 9.2 八窍材料

材料按八窍属性划分（烛/尸/星/渊/梦/噬/帘/疫），典型药草如：翠芽草（尸）、赤焰花（渊）、寒水芹（星）、铁线蕨（烛）、血藤根（尸）、石灯芝（梦）等。

### 9.3 制香（香品炼制）

- 玩家以「香材」炼制「香品」，可用「香意」描述期望的香性（如「存仿回元，香性温和，不求猛烈」）。
- 香性由 AI 规划师结合材料语义、八窍属性、剂量与香意生成，分「温和/猛烈」等维度。
- 炼制结果有随机性（香变），可能出现「坏香」——品质凡品，效果差强人意，属于正常游戏机制。

## 十、核心叙事基调

窥渊录的叙事遵循以下基调（来自 `character-generation.md` / `fate-naming.md` / `dungeon-round.md` 等 prompt）：

1. **白描恐怖**：写诡异不写判断词，用残缺、错位、不可完整读出的「讳名」营造恐怖。
2. **执念即弱点**：腌物、遗种的弱点都源于其生前执念。
3. **灯与渊的日常**：守灯是日复一日、以命相抵的日常，而非英雄史诗。
4. **知识即代价**：知道得越多，疯得越彻底——观星台是这一主题的化身。
5. **道德灰域**：白莲乳母教「作恶，但收容的人无处可去」；幽都交易记忆——没有纯粹的正邪。
6. **谁执灯谁便离人远**：修得越深、越接近「渡渊」，便越不像人——力量与代价一体两面。
